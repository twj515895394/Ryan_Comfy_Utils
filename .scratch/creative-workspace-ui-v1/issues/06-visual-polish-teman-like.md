# 06 视觉 polish（TE_MAN 观感）

## 父问题

- `.scratch/creative-workspace-ui-v1/PRD.md`

## 要构建什么

在功能齐后统一视觉：暗色层级、圆角、间距、主按钮/次按钮、消息气泡、侧栏选中态、空状态文案区、顶栏工具条与 TE_MAN 同排不违和。  
允许参照 TE_MAN 配色与密度；不要求像素级一致，但截图并排时不应再是“调试表单”。

## 验收标准

- [ ] 空状态有引导文案（非空白灰盒）
- [ ] 消息用户/助手样式区分明显
- [ ] 主操作（发送/确认）与次操作层级清晰
- [ ] 面板默认尺寸接近可用聊天窗口（非过窄工具条）
- [ ] 用户硬刷新后观感可接受（手测）
