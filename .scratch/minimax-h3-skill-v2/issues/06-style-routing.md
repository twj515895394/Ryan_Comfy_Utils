## 要构建什么

建立独立、可扩展的官方风格路由层。首版支持官方当前八种风格：极简产品广告、3D 动画短片、纸艺定格解释、品牌宣传片、音乐视频字幕、双人合作游戏开场、纸张拼贴解释、手绘实拍混合。风格配置只注入专属约束，不改变 H3 基础模式和字段协议。

## 验收标准

- [ ] 通用核心、风格路由和风格配置的职责边界明确。
- [ ] 用户明确风格或任务意图时才能触发风格路由，普通请求不会被强行套用风格。
- [ ] 八种官方风格各有适用任务、不适用任务、视觉语言、镜头/节奏、声音/文字策略和专属检查项。
- [ ] 风格路由不覆盖用户明确的主体、台词、素材用途、修改项和禁止项。
- [ ] 风格不匹配或信息不足时可退回通用模式，并说明必要假设。
- [ ] 后续增加风格只需增加配置和规则，不需要修改通用模式、素材标签和字段协议。
