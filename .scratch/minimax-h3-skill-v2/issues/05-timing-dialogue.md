## 父问题

`.scratch/minimax-h3-skill-v2/PRD.md`

## 要构建什么

统一 H3 的时间、镜头、说话人、对白、画面文字和声音控制规则，提升多镜头广告、MV、对白和旁白任务的可生成性。

## 验收标准

- [ ] 后续 Shot 使用严格递增的 `MM:SS.mmm` 切镜时间，关键帧使用两位小数对齐。
- [ ] 镜头运动能够表达类型、必要的幅度和必要的速度。
- [ ] 同一说话人跨镜使用稳定 `(S1)`、`(S2)`，多人合说有明确规则。
- [ ] 对白和歌词使用 `<d>[Language] ...</d>`，跨镜台词使用 `<scenetrans>`，末尾截断使用 `<cutoff>`。
- [ ] 画外音明确说话人且说明画面人物嘴唇闭合。
- [ ] 可见字幕、标题、Logo、按钮和 UI 文案逐字保留，并使用明确的位置、时间和可读性约束。
- [ ] 台词长度与镜头时长匹配，不把环境声或 BGM重复写入对白字段。
