# MiniMax H3 Skill v2

**状态：** 已确认设计，待按依赖顺序实现

## 目标

将当前中文 MiniMax H3 提示词 skill 与官方 `h3-prompt-writing` 和官方八种风格能力整合为统一、可扩展、可回归验证的 skill。

## 范围

- 支持 T2VA、I2VA、FL2VA、L2VA、Ref2VA。
- 支持视频编辑、视频续接、音频复用和音频参考关系。
- 保留中文用户可读层，最终 H3 prompt 默认使用官方英文字段结构；对白、歌词、字幕、Logo 和 UI 文案保留原文。
- 保留 `@图片N`、`@视频N`、`@音频N`，内部映射官方 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>`。
- 首版路由官方八种风格：极简产品广告、3D 动画短片、纸艺定格解释、品牌宣传片、音乐视频字幕、双人合作游戏开场、纸张拼贴解释、手绘实拍混合。
- 风格采用通用核心 + 风格路由 + 风格配置，后续可扩展。

## 非目标

不调用 API、不生成媒体、不声称完成文件校验、不虚构品牌事实；不把风格规则复制进通用核心。
