# MiniMax H3 Skill v2 实施计划

> 该计划基于 `design.md`，先发布垂直切片 issues，再按依赖顺序实现。当前阶段不修改 skill 实现文件。

**目标：** 将当前 MiniMax H3 提示词 skill 升级为兼容官方模式协议、具备完整素材/音频/时间控制，并支持官方八种风格可扩展路由的版本。

**架构：** 保留中文用户可读层；将官方 H3 prompt 作为稳定内部输出协议；以模式矩阵和素材引用模型承接基础生成、全参考、视频编辑和音频关系；风格通过独立配置路由注入。

**技术栈：** Markdown skill 文档、引用规则、模板、质量检查清单和代表性场景回归。

---

## 阶段 1：模式与契约

### 任务 1.1：确认统一模式矩阵

**修改：** `SKILL.md`、`references/h3-prompt-rules.md`

- 将当前模式映射到 T2VA、I2VA、FL2VA、L2VA、Ref2VA。
- 补充 Video Editing、Video Continuation、Audio Reuse、Audio Reference。
- 明确普通图生不默认等于 I2VA，单张图片不默认等于关键帧。
- 保留用户语言层，增加英文官方 prompt 层。

**验证：** 用无素材、单图、首帧、首尾帧、尾帧、原视频编辑和视频续接请求逐项确认模式唯一且不冲突。

### 任务 1.2：确认素材和引用模型

**修改：** `SKILL.md`、`references/h3-prompt-rules.md`

- 保留 `@图片N`、`@视频N`、`@音频N`。
- 增加 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` 的映射规则。
- 增加视觉保留关系和音频关系。
- 处理一份素材多角色、来源文件与内容对象分离、编号冲突。

**验证：** 用人物图、场景图、动作视频、运镜视频和音频混合输入检查每个标签的用途、锁定范围和未参考维度。

---

## 阶段 2：输出协议与时间声音

### 任务 2.1：升级基础模式模板

**修改：** `references/h3-prompt-templates.md`

- 增加 T2VA、I2VA、FL2VA、L2VA 模板。
- 关键帧模式增加官方对齐指令。
- 基础输出使用 `integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music`。
- 保留中文用户可读的模式判断和素材映射。

**验证：** 检查字段顺序、关键帧时间点、第一镜/后续切镜格式和单一连续动作表达。

### 任务 2.2：升级 Ref2VA、视频编辑和音频模板

**修改：** `references/h3-prompt-templates.md`、`references/h3-prompt-rules.md`

- 增加 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description` 六段模板。
- 将视频编辑、背景替换、对象替换、声音替换纳入 Ref2VA 关系。
- 增加视频续接模板。
- 区分音频完整复用、部分复用、音色/节奏参考。

**验证：** 检查编辑原视频、从原视频结尾续接、保留原音频、替换台词音色四类请求。

### 任务 2.3：增强镜头、对白和声音规则

**修改：** `references/h3-prompt-rules.md`

- 增加标准时间格式和递增切镜要求。
- 增加镜头运动类型/幅度/速度词典。
- 增加稳定 speaker ID、`<d>`、`<scenetrans>`、`<cutoff>`。
- 增加画面文字双引号、原文保留和画外音闭唇规则。
- 拆分画内声音、环境声和非叙事音乐。

**验证：** 用多说话人、跨镜台词、旁白、现场音乐、无 BGM 和可见 UI 文案场景检查。

## 阶段 3：官方风格路由

### 任务 3.1：建立风格路由边界

**修改：** `SKILL.md`，必要时新增 `references/h3-style-routing.md`

- 定义通用核心、风格路由和风格配置的边界。
- 仅在用户明确风格或任务意图时路由。
- 风格配置不得改变基础 H3 模式、素材标签和字段协议。
- 风格不匹配时退回通用模式。

**验证：** 用普通文生、产品广告、MV、纸艺、3D 动画、游戏开场和手绘实拍请求检查路由结果。

### 任务 3.2：加入官方八种风格配置

**修改：** `references/h3-style-routing.md` 或拆分为独立风格 reference 文件

加入：

- 极简产品广告
- 3D 动画短片
- 纸艺定格解释
- 品牌宣传片
- 音乐视频字幕
- 双人合作游戏开场
- 纸张拼贴解释
- 手绘实拍混合

每种风格只维护适用范围、默认视觉语言、节奏/镜头、声音策略、文字策略、是否需要分镜阶段和风格专属检查项。

**验证：** 每种风格至少有一个可路由场景；通用请求不会误触发风格配置。

---

## 阶段 4：质量检查与回归

### 任务 4.1：更新质量清单

**修改：** `references/h3-quality-checklist.md`

- 增加五种官方基础模式和 Ref2VA 检查。
- 增加视频续接、音频复用/参考和风格路由检查。
- 增加关键帧时间、speaker ID、跨镜对白和 Shot 起止状态检查。
- 保留现有超限、原文保护和不静默丢弃规则。

**验证：** 至少覆盖 10 个正常/边界/冲突场景，且每条检查项能防止一个具体错误。

### 任务 4.2：执行最终一致性审查

**检查：** `SKILL.md`、`references/h3-prompt-rules.md`、`references/h3-prompt-templates.md`、`references/h3-quality-checklist.md`

- 模式名称、字段名称、标签名称完全一致。
- 模板没有使用规则未定义的标签或术语。
- 检查清单覆盖设计文档全部要求。
- 没有旧规则残留导致模式冲突。
- 八种风格全部有路由说明，且没有把官方外部内容未经筛选地复制进 skill。

**验证：** 执行代表性场景回归并记录未覆盖风险。
