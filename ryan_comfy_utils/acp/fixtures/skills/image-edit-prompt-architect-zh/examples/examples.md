# 使用示例

## 示例 1：在原图上换装并锁定人脸

用户意图：

> 保持原人物脸部不变，将休闲上衣替换成黑色商务西装。

优化后的提示词：

```text
请直接编辑图片1。图片1是最终画面的原始底图，这不是重新生成人物的任务。

只将人物当前穿着的休闲上衣替换为合身的黑色商务西装外套和白色衬衫。新服装必须自然贴合人物现有姿势、肩部和躯干结构，保留真实布料褶皱、领口遮挡、接触关系和原场景光影。

人物的头部、面部和身份不属于编辑区域。不得重新生成、重绘、美化、磨皮或重新设计脸部；保持原图中的脸型、五官位置比例、表情、视线、肤色、年龄感、发型、发际线和头部角度不变。

保持身体比例、姿势、手势、相机角度、人物位置、背景、构图和光线不变。不得瘦身、改变肩宽或修改手部。

除服装外，不修改任何其他内容。最终结果应像在原始照片中直接更换了衣服，而不是重新拍摄或重新生成了一个相似人物。
```

## 示例 2：根据参考人物生成新场景

用户意图：

> 使用图片1中的人物，生成一张夜晚雨中行走在东京街道的全身照片。

优化后的提示词：

```text
图片1是唯一人物身份参考图，用于定义人物的真实身份、脸型、五官几何、肤色、年龄感、发际线和稳定外貌特征。请基于图片1中的同一个人生成一张全新的全身照片。

场景为夜晚雨中的东京街道，人物撑透明雨伞自然行走，穿深色长风衣和简洁皮鞋。镜头为略低机位的三分之二全身构图，街面有真实雨水反光，背景霓虹虚化，人物面部仍清晰可辨。光线来自街灯和招牌，方向、强度与人物阴影保持一致。

新图中的人物必须明确是图片1中的同一个人，而不是相似演员或通用模特脸。保持图片1人物的整体脸型、眼睛形状和眼距、眉眼关系、鼻梁与鼻翼结构、嘴唇轮廓、颧骨、下颌线、下巴比例、肤色、年龄感、发际线和自然不对称特征。允许根据行走姿势、镜头角度和夜间光线自然重建面部，但不得瘦脸、放大眼睛、抬高鼻梁、修改嘴唇、年轻化、磨皮或偶像化。

不得从场景中的路人或其他视觉元素借用任何面部特征。最终结果应像图片1中的真人在雨夜东京街头重新拍摄的一张照片。
```

## 示例 3：四张参考图职责隔离

用户意图：

- 图片1：人物身份
- 图片2：服装
- 图片3：姿势
- 图片4：场景

优化后的提示词开头：

```text
图片1是唯一人物身份参考，只用于脸型、五官、肤色、年龄感、发际线和人物身份。
图片2只提供服装款式、颜色、材质和裁剪，不提供人物脸部、发型、体型或身份。
图片3只提供身体姿势、手势和身体朝向，不提供人物脸部、服装、肤色或身份。
图片4只提供场景、环境、构图氛围和光线参考，不提供人物身份。

不得融合图片2、图片3或图片4中任何人物的脸型、五官、发型、肤色、年龄或身份特征。冲突时优先级为：本提示中的明确要求 > 图片1人物身份 > 图片3姿势 > 图片2服装 > 图片4场景。
```

## 示例 4：精确替换聊天气泡文字

```text
请直接编辑图片1，只替换聊天气泡中的原文字。

将文字精确替换为以下内容，并严格保持以下换行：
“问了下，情况是这样的，34500含税，这个是现在的分销价格。正常未税下8%.
31850 未税保修3年；31300 未税 保修1年”

不得改写、翻译、纠错、增删标点或数字。保持原气泡的位置、尺寸、圆角、背景色、字体风格、字号、字重、行距、对齐方式和文字区域透视。除文字内容外，图片中的人物、头像、时间、界面结构、背景和其他像素全部保持不变。
```

## 示例 5：手中物体替换

用户意图：

> 将图片1人物手中的石头替换为图片2中的卫生纸包装，其他内容不变。

优化后的提示词：

```text
请直接编辑图片1。图片1是原始底图，图片2只作为目标卫生纸包装的外观参考。

只将图片1人物手中的石头替换为图片2所示的一整包卫生纸。保持图片2包装的整体尺寸比例、包装形状、主色、Logo 位置、图案布局和包装材质，不得增加图片2中不存在的文字、图案或结构。

保持图片1人物的脸部、身份、发型、表情、身体、姿势、手臂和手腕角度不变。尽量保持原有手部姿态，并使手指与新包装形成自然可信的握持和遮挡关系。新包装的透视、尺寸、受光方向、接触阴影和投射阴影必须与图片1原场景一致。

彻底移除原石头的所有轮廓、纹理、阴影和残留。除手中物体及其必要的接触区域外，不修改任何其他内容。
```
