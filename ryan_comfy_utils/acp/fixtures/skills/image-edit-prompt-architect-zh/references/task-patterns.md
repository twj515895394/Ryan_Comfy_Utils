# 常见任务构建模式

以下内容用于提示词构建，不要求逐字照抄。

## 模式 1：在原图上更换服装

结构：

1. 将图片1声明为原始底图，直接在其上编辑。
2. 只替换当前服装。
3. 人脸和头部不属于编辑范围。
4. 保持人物身份、姿势、身体比例、手部、相机、背景和光线。
5. 保证布料褶皱、接触、遮挡和阴影合理。
6. 除非用户要求，不修改皮肤、身材、五官或发型。

## 模式 2：更换背景

结构：

1. 人物和前景主体保持不变。
2. 只替换背景。
3. 匹配透视、地平线、比例、景深、色温和光线方向。
4. 保持头发边缘、透明材质、反射、接触阴影和前景轮廓。
5. 不重新设计人物。

## 模式 3：替换手中物体

结构：

1. 只替换人物手中的指定物体。
2. 保持手势、手指数目、握持逻辑、手腕角度、手臂姿势和人物身份。
3. 匹配新物体大小、透视、接触点、遮挡和投射阴影。
4. 清除原物体的全部残留。
5. 不修改周围场景。

## 模式 4：根据参考脸生成新的全身图片

结构：

1. 将身份参考图声明为唯一人物身份来源。
2. 按用户要求生成新的全身姿势、服装、场景、机位和光线。
3. 保持面部几何和具有身份辨识度的特征。
4. 根据新的距离和角度自然重建。
5. 不美化、不平均化、不替换成通用脸。
6. 除非同一参考图也定义身体比例，否则不要把人物脸部身份和身体设计混为一谈。

## 模式 5：身份 + 服装 + 姿势 + 场景多图组合

结构：

- 图片1：只提供人物身份。
- 图片2：只提供服装。
- 图片3：只提供姿势。
- 图片4：只提供场景。
- 明确禁止职责串用。
- 默认优先级：用户要求 > 人物身份 > 原图/姿势 > 服装 > 场景 > 风格。

## 模式 6：保持人脸并修改发型

结构：

1. 直接编辑原始底图。
2. 只修改头发，并具体说明长度、轮廓、分缝、纹理和颜色。
3. 保持脸部、耳朵、额头几何、眉眼关系和表情。
4. 除非用户要求改变发际线，否则保持原发际线。
5. 保持头部大小和头骨轮廓。

## 模式 7：姿势迁移

结构：

1. 人物身份来源和姿势来源必须分离。
2. 新图人物身份来自身份参考图。
3. 只迁移姿势图中的骨架姿态、手势、身体朝向和面对镜头的方向。
4. 不复制姿势参考人物的脸、身体身份、服装或肤色细节。
5. 明确身体比例来自身份图还是姿势图。

## 模式 8：风格迁移

结构：

1. 明确风格作用于整张图，还是不作用于人脸。
2. 保持人物身份几何和构图。
3. 迁移配色、线条、明暗、纹理、媒介和渲染方式。
4. 不迁移风格参考图中某个角色的五官设计。
5. 能用视觉属性描述时，避免使用模糊的艺术家模仿描述。

## 模式 9：图片文字替换

结构：

1. 完整引用替换文字。
2. 明确精确换行。
3. 保持标点、数字、符号和大小写。
4. 匹配位置、对齐、大小、透视、字体特征、颜色和表面纹理。
5. 不得翻译、改写、自动纠错或增加文字。
6. 保持文字区域外的所有像素不变。

## 模式 10：商品或包装一致性

结构：

1. 将商品参考图设为事实来源。
2. 保持轮廓、比例、包装结构、Logo 位置、品牌色、标签版式和材质。
3. 只修改用户要求的场景、角度、手部互动或环境。
4. 不添加不存在的文字、标记、按钮、缝线或配件。
5. 反射和阴影必须与新场景一致。

## 模式 11：删除物体

结构：

1. 只删除指定物体，并清除其反射、阴影和遮挡痕迹。
2. 根据周围内容保守重建被遮挡背景。
3. 保持人物、人脸、构图、透视和无关物体。
4. 除非用户要求，不用其他物体替代。

## 模式 12：修复与增强

结构：

1. 修复指定缺陷：划痕、污渍、撕裂、褪色、噪点、模糊或压缩损伤。
2. 保持人物身份、几何、年代、服装、原构图、颗粒感和真实纹理。
3. 只恢复有原图证据支持的细节。
4. 不现代化、不美化、不编造文字，也不增加没有依据的五官。
