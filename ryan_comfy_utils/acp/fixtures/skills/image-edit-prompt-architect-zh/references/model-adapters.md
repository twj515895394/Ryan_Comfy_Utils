# 目标模型适配规则

先构建通用提示词结构，再进行最少但有效的模型适配。

## GPT Image / ChatGPT 图片编辑器

优先使用明确的编辑式语言：

- “直接编辑图片1”
- “只修改……”
- “其余内容保持不变”
- “图片1是唯一人物身份参考”
- “图片2只提供服装/动作/场景，不提供人脸”

原图编辑任务中，应在提示词开头附近写明编辑目标，并在结尾附近再次强调最重要的不变量。

参考人物生成新图时，要区分“稳定人物身份”与“随角度自然重建的面部”。改变机位后，不要要求人脸像素完全一致。

## Nano Banana / Gemini 图片编辑器

使用清晰、紧凑的结构化指令：

- 图片职责映射
- 目标变化
- 唯一身份来源
- 必须保持的元素
- 禁止跨图片串用的内容
- 输出构图

除非确有必要，不要让同一张参考图承担多个相互重叠的职责。人物身份参考和风格参考要清晰隔离。

## 通用多模态图片编辑器

使用模型中性的结构：

1. 图片职责
2. 精确变化
3. 必须保持
4. 不得从次要参考图复制的内容
5. 相机、构图和光线
6. 正确结果的视觉判定

## 扩散模型 / 局部重绘工作流

当用户提到蒙版、Inpainting、重绘强度、ControlNet、IP-Adapter、InstantID、FaceID 等工作流时，本 Skill 仍然只输出提示词文字。

必要时可以分别输出：

- 正向提示词
- 负向提示词
- 使用自然语言描述的蒙版范围建议
- 人物身份/参考图职责说明

除非用户明确要求参数建议，并提供了具体工作流，否则不要擅自编造采样器、CFG、重绘强度或适配器权重。
