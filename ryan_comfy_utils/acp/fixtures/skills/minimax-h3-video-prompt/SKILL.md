# MiniMax H3 视频提示词编排

## 目标与边界

将用户的创意、编辑意图和有序多模态素材整理成 H3 可直接理解的提示词。只负责理解、编排、补全和检查，不调用 API，不生成或编辑媒体文件。

保持用户明确的主体、事件、人物关系、台词、字幕、Logo 文案和关键修改要求；只补充低风险的场景细节、镜头、动作、声音和禁止项。

## 何时使用

当请求涉及以下任一项时使用本技能：

- 根据一句创意生成 H3 文生视频提示词。
- 根据一张或多张图片生成视频、首帧/尾帧过渡提示词。
- 组合人物图、场景图、动作视频、运镜视频、音频等素材生成提示词。
- 编辑原视频中的人物、物体、背景、光影、字幕、台词、音色或声音。
- 将简短、口语化或不完整的描述改写成 H3 友好的提示词。

## 执行流程

### 1. 解析意图

先区分：纯文生、普通图生、首尾帧、全能参考、视频编辑或已有提示词改写。将用户最新且最具体的要求视为最高优先级。

### 2. 登记素材并归一化编号

为每个素材建立内部登记：介质类型、H3 标签、用户别名、用途、锁定特征、可变范围和冲突备注。使用 `@图片N`、`@视频N`、`@音频N` 引用素材。

编号优先级：用户明确映射 > 用户文本别名（`图1`、`图片1`、`image01`）> 文件名中的明确序号 > 当前上传顺序。不要仅凭文件名猜用途。一个素材可以承担多个角色，但必须逐项说明“锁定什么、不要参考什么”。

### 3. 选择模式

- 没有素材：使用纯文生。
- 1 张图片：只有用户明确指定首帧或尾帧时才使用首/尾帧语义；否则按普通参考图处理。
- 2 张图片：只有用户明确指定第一张首帧、第二张尾帧时才使用首尾帧模式。
- 图片、视频、音频混合：使用全能参考，并为每个素材写用途。
- 用户要求“在原视频中替换/增加/删除/修改”：使用视频编辑结构，保护未修改内容。

首尾帧模式只描述两帧之间的连续动作、光影和声音，不擅自加入切镜。用户明确要求多镜头时，改用普通多模态参考并在必要提醒中说明。

### 4. 编排提示词

按以下顺序生成：

1. 参考素材说明：逐项写明 `@` 素材的用途和锁定维度。
2. 核心创意：写清主体、地点、事件、题材/风格、时长、画幅、运镜和切镜意图。
3. 画面过程说明：简单动作用连续时间线；多事件、多场景或强节奏任务按 Shot 拆分。
4. 声音与文字：写清对白、环境声、动作声、音乐、音色和屏幕文字原文。
5. 保持项与禁止项：明确不要新增、不要改动、不要出现的内容。

详细规则和模板见：

- [H3 规则](references/h3-prompt-rules.md)
- [提示词模板](references/h3-prompt-templates.md)
- [质量检查](references/h3-quality-checklist.md)

### 5. 处理不完整信息

采用“保核心、补细节”：自动补全合理的镜头、动作、场景、声音和负面约束，不改变核心故事。只有素材用途、首尾帧身份、时长/画幅等会改变生成模式的缺失信息，才在必要提醒中提出一个具体问题；其余情况直接基于明确假设完成提示词。

### 6. 检查限制

交付前检查时长、画幅、素材数量、视频总时长、`@` 标签闭环、提示词长度、文字原文、保持项和禁止项。超限时不静默丢弃素材：先按用户意图给出高优先级筛选或分批方案；无法安全筛选时明确提醒。提示词超过 7000 字符时压缩重复修饰，并告知已压缩。

## 输出格式

默认按以下顺序输出：

### 模式判断
纯文生 / 普通图生 / 首尾帧 / 全能参考 / 视频编辑

### 素材映射
- @图片1：用途；锁定特征；不参考的维度
- @视频1：用途；锁定特征；不参考的维度

### 可直接复制的 H3 提示词
```text
参考素材说明：...
核心创意：...
画面过程说明：...
声音与文字：...
保持项与禁止项：...
```

### 必要提醒
仅在存在超限、冲突或关键假设时输出。

用户未指定语言时使用中文；用户明确要求英文、日文等时整体切换；台词、字幕、Logo、按钮和 UI 文案保留用户原文。用户未提音乐时默认写环境声和动作声，不主动添加背景音乐；用户明确不要音乐时写 `非叙事性音乐：N/A`。
