# MiniMax H3 视频提示词编排

## 目标与边界

将用户的创意、编辑意图和有序多模态素材整理成 H3 可直接理解的提示词。只负责理解、编排、补全和检查，不调用 API，不生成或编辑媒体文件。

保持用户明确的主体、事件、人物关系、台词、字幕、Logo 文案和关键修改要求；只补充低风险的场景细节、镜头、动作、声音和禁止项。

## 何时使用

当请求涉及以下任一项时使用本技能：

- 根据一句创意生成 H3 文生视频提示词（T2VA）。
- 根据首帧图片向后生成视频（I2VA）。
- 根据首帧和尾帧描述连续补间（FL2VA）。
- 根据尾帧反推前置状态并生成到尾帧（L2VA）。
- 组合人物图、场景图、动作视频、运镜视频、音频等素材生成全参考提示词（Ref2VA）。
- 编辑原视频中的人物、物体、背景、光影、字幕、台词、音色或声音。
- 从原视频结尾继续、延长或衔接新内容。
- 将简短、口语化或不完整的描述改写成 H3 友好的提示词。

## 执行流程

### 1. 解析意图并选择模式

先判断基础模式，再判断是否存在全参考、编辑、续接或音频关系：

- 无素材：T2VA。
- 单图且未明确首帧/尾帧：普通参考图，不升级为 I2VA。
- 明确首帧：I2VA。
- 明确首帧和尾帧：FL2VA；默认描述连续补间，不自动加入切镜。
- 明确尾帧但没有首帧：L2VA；让动作和构图逐渐收敛到最后有效时刻。
- 多素材共同参与生成：Ref2VA。
- 原视频被直接修改：Video Editing。
- 从原视频结尾继续：Video Continuation。
- 原声音被直接复制：Audio Reuse；只参考音色、节奏或质感：Audio Reference。

这些关系可以组合，例如 `[video editing + audio reuse]`。如果用户明确要求多镜头，关键帧任务改用相应的多模态/全参考表达，并在必要提醒中说明影响。

### 2. 登记素材和引用关系

为每个素材建立内部登记：介质类型、用户标签、官方标签、来源、用途、锁定特征、可变范围和冲突备注。

- 用户层使用 `@图片N`、`@视频N`、`@音频N`。
- H3 结构层映射 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>`。
- 编号优先级：用户明确映射 > 文本别名 > 文件名明确序号 > 当前上传顺序。
- 不要仅凭文件名猜用途；同一素材承担多个角色时逐项说明锁定、仅参考和禁止参考的维度。
- 区分来源文件、可复用内容对象和目标视频中的引用角色。

### 3. 编排 H3 prompt

先写可读的素材映射，再按模式选择官方结构：

- 基础模式使用 `integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music`。
- Ref2VA 使用 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music`。
- 第一镜使用 `[Shot 1]`；后续切镜使用严格递增的 `MM:SS.mmm`。
- 单一连续动作使用时间线；多事件、多场景或强节奏内容按 Shot 拆分。
- 每个 Shot 写景别、主体位置、动作、镜头运动、声音和切换方式。

### 4. 处理声音和文字

- 画面时间线写对白、歌唱和画内声音。
- `overall_soundscape` 总结环境声、动作声和非语言人声，不重复对白。
- `non_diegetic_music` 只写角色听不到的背景音乐；用户未提音乐时不主动添加 BGM。
- 说话人使用稳定 `(S1)`、`(S2)`；对白和歌词使用 `<d>[Language] ...</d>`。
- 跨镜对白使用 `<scenetrans>`；视频结尾截断使用 `<cutoff>`；画外音明确嘴唇闭合。
- 字幕、标题、Logo、按钮和 UI 文案逐字保留，写明位置、时间和可读性。

### 5. 可选风格路由

只有用户明确风格或任务意图时才启用风格路由。首版支持官方八种风格：极简产品广告、3D 动画短片、纸艺定格解释、品牌宣传片、音乐视频字幕、双人合作游戏开场、纸张拼贴解释、手绘实拍混合。

风格只注入视觉、节奏、声音、文字和生产阶段约束，不改变 H3 基础模式、素材标签或字段顺序。风格不匹配时退回通用模式；后续增加风格只增加配置。

### 6. 处理不完整信息

采用“保核心、补细节”：自动补全低风险的镜头、动作、场景、声音和禁止项，不改变核心故事。只有会改变模式的素材角色、首尾帧身份、时长或画幅缺失时，才提出一个具体问题；其余情况基于明确假设完成。

### 7. 检查限制

交付前检查时长、画幅、素材数量、视频总时长、标签闭环、提示词长度、时间线、原文、保持项、禁止项和风格路由。超限时不静默丢弃素材：给出优先级筛选或分批方案。提示词超过 7000 字符时只压缩重复修饰，并告知已压缩。

## 输出格式

默认按以下顺序输出：

### 模式判断

基础模式：T2VA / I2VA / FL2VA / L2VA / Ref2VA  
附加关系：Video Editing / Video Continuation / Audio Reuse / Audio Reference

### 素材映射

- `@图片1` → `<Picture 1>` 或 `<Subject N>`：用途；锁定特征；不参考的维度。
- `@视频1` → `<Video 1>` 或 `<Subject N>`：用途；锁定特征；不参考的维度。
- `@音频1` → `<Audio 1>`：完整复用、部分复用或仅参考的范围。

### 可直接复制的 H3 提示词

基础模式：

```text
[关键帧对齐指令（仅 I2VA/FL2VA/L2VA）]

integrated_multimodal_description: ...

overall_soundscape: ...

non_diegetic_music: ...
```

Ref2VA：

```text
subject_definitions: ...

summary: ...

retention_analysis: ...

detailed_description: ...

overall_soundscape: ...

non_diegetic_music: ...
```

### 必要提醒

仅在存在超限、冲突或关键假设时输出。

用户解释和素材映射默认使用用户语言；最终 H3 prompt 默认使用官方英文结构。用户明确要求其他语言时切换解释层，但台词、歌词、字幕、Logo、按钮和 UI 文案始终保留原文。用户未提音乐时只写环境声和动作声；用户明确不要音乐时写 `non_diegetic_music: N/A`。
