# MiniMax H3 风格路由

风格路由是可选层，不改变 T2VA、I2VA、FL2VA、L2VA、Ref2VA、视频编辑、视频续接和音频关系协议。只有用户明确风格或任务意图时才触发；不匹配时退回通用模式。

## 路由字段

每种风格维护：适用任务、不适用任务、视觉媒介、镜头与节奏、主体一致性、声音策略、文字策略、阶段确认和专属检查项。

## 首版官方风格

### 1. 极简产品广告

- 适用：产品展示、电商短片、产品发布。
- 不适用：KOC 口播、复杂屏幕演示、一般视频编辑。
- 约束：产品形状、材质、颜色、Logo 和卖点必须来自用户素材或明确文本；使用克制构图、干净背景、受控移动和有节奏的产品特写。
- 声音/文字：用户未指定时不添加 BGM；卖点和 CTA 必须逐字保留。
- 检查：产品身份、比例、Logo、卖点和 CTA 不被模型补写或改写。

### 2. 3D 动画短片

- 适用：角色驱动的完整短故事、3D CG 叙事。
- 不适用：单个写实镜头、普通视频编辑、纯静态产品图生。
- 约束：先锁定项目 brief、角色卡、场景卡和 Shot 顺序；每个 Shot 单独生成，跨 Shot 保持角色、服装、比例、空间和动作连续。
- 声音/文字：按 Shot 设计对白、音效和音乐，不把整部故事压进一个 Shot。
- 检查：角色一致性、场景连续性、动作起止状态、镜头和音频衔接。

### 3. 纸艺定格解释

- 适用：科学、教育和知识解释，纸张、立体书、分层纸景和定格动画。
- 不适用：写实动作、复杂真人表演、需要真实物理拍摄的素材。
- 约束：先抽取知识目标和视觉隐喻，锁定纸张层次、角色、道具、材质和手工边缘；动作采用可见的纸片移动、折叠、翻页或弹出。
- 声音/文字：保留纸张摩擦、翻页、剪切和轻触等触感声音；旁白和字幕只有用户要求时加入。
- 检查：纸张材质、层次关系、定格节奏、知识表达和触感声音。

### 4. 品牌宣传片

- 适用：品牌、产品、网站、应用、商店和个人项目宣传。
- 不适用：未经授权模仿真实品牌标志、虚构产品声明、单纯风格测试。
- 约束：先登记品牌事实、用户资产来源、核心卖点、使用场景和 CTA，再组织节拍和 Shot；不得虚构能力、客户或数据。
- 声音/文字：品牌名称、Logo、产品声明和 CTA 逐字来自用户；配音、音乐和环境声分开定义。
- 检查：资产 provenance、品牌事实、Logo 文案、卖点、CTA 和授权边界。

### 5. 音乐视频字幕

- 适用：MV、歌词视频、节拍驱动的字幕和情绪化视觉短片。
- 不适用：无歌词的普通产品广告、完全静音视频、需要严格对白口型的编辑任务。
- 约束：分析节拍、演唱时间和歌词分段；文字位置、层级、出现/消失、运动和可读性必须与音乐时间线一致。
- 声音/文字：歌词原文不可改写；明确音频是完整复用还是仅参考节奏/音色；不擅自添加旁白。
- 检查：歌词完整、节拍同步、字幕可读、音频关系正确、跨 Shot 文字连续。

### 6. 双人合作游戏开场

- 适用：双角色游戏菜单、合作游戏开场、角色选择和玩家卡片动画。
- 不适用：单角色广告、无 UI 文案的普通动作镜头、复杂游戏实机演示。
- 约束：锁定两名角色的身份线索、颜色、玩家卡、按钮、图标、菜单框架和交互事件；先确认静态构图，再描述按钮和角色动效。
- 声音/文字：按钮、玩家标签、角色名和提示语逐字保留；交互音效与背景音乐分开。
- 检查：两名角色区分度、UI 文案、按钮状态、图标位置、颜色协调和交互顺序。

### 7. 纸张拼贴解释

- 适用：观点、知识点、抽象主题和社交媒体 B-roll 的拼贴视觉解释。
- 不适用：需要写实人物表演、连续真实物理运动或高精度 UI 的任务。
- 约束：先提取主题和视觉隐喻，再组织半色调、剪纸、撕裂边缘、层叠纸片和可见手工移动；默认保留拼贴音效。
- 声音/文字：默认不添加 BGM、旁白或字幕，除非用户明确要求；用户给定文字必须原文保留。
- 检查：隐喻与主题对应、纸张层次、拼贴运动、音效默认值和文字请求。

### 8. 手绘实拍混合

- 适用：粗糙发光手绘动画与真实空间接触、变形和追逐的单场景短片。
- 不适用：精致 CG、恐怖跳吓、毛绒角色、多场景复杂剪辑。
- 约束：先明确真实空间中的接触点、连续变形路径、逃逸方向和延迟手持追拍；保持粗糙发光线条和非恐怖语气。
- 声音/文字：环境声和接触动作声优先；不要因风格自动添加旁白或音乐。
- 检查：接触可信度、变形连续性、镜头延迟、线条质感、空间关系和非恐怖边界。

## 路由优先级

1. 用户明确指定的模式、主体、素材角色、台词和修改项。
2. 用户明确指定的风格或任务类型。
3. 当前风格配置的默认约束。
4. 通用 H3 安全补全。

风格配置不能覆盖第 1 项。未来新增风格必须沿用本文件的字段和优先级，不得创建第二套素材编号或 prompt 字段。
