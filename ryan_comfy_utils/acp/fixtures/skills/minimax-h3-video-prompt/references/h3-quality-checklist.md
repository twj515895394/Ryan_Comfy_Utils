# MiniMax H3 质量检查与验收

## 交付前检查表

### 模式与关系

- [ ] 已判断 T2VA、I2VA、FL2VA、L2VA、Ref2VA 或视频编辑/续接关系。
- [ ] 普通单图没有被未经授权写成首帧或尾帧。
- [ ] FL2VA 的首帧和尾帧身份明确，L2VA 的尾帧落在视频最后有效时刻。
- [ ] 视频编辑、视频续接、音频复用和音频参考没有混淆。
- [ ] 关键帧与 Shot 的时间对齐明确。

### 素材与引用

- [ ] 每个 `@图片N`、`@视频N`、`@音频N` 都对应实际素材。
- [ ] 用户明确映射优先于文本别名、文件名序号和上传顺序。
- [ ] `@` 标签与 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` 的映射闭环。
- [ ] 每个素材用途清晰，锁定、不参考和可变维度没有混淆。
- [ ] 同一素材多角色时逐项定义，不把来源文件误当成目标内容对象。
- [ ] 视觉保留关系和音频关系使用了正确的关系词。
- [ ] 没有复制参考图中未指定的 Logo、标题、品牌或水印。

### 创意与画面

- [ ] 核心创意包含主体、地点、事件、媒介/风格、时长和画幅。
- [ ] `integrated_multimodal_description` 或 `detailed_description` 按播放顺序组织。
- [ ] 第一镜使用 `[Shot 1]`；后续 Shot 的 `MM:SS.mmm` 时间严格递增。
- [ ] 简单动作使用连续时间线；复杂内容按信息负荷拆分 Shot。
- [ ] 每个 Shot 有景别、主体位置、动作、镜头运动和切换方式。
- [ ] 每个 Shot 有可观察的起始状态和结束状态，不堆叠互相独立的主要动作。
- [ ] 镜头运动在需要时包含类型、幅度和速度，且不与主体运动冲突。
- [ ] 已写需要保持的角色、物体、动作、构图、空间、透视和光影。
- [ ] 视频续接从原视频最后有效状态开始，不重复已经完成的动作。

### 台词、文字和声音

- [ ] 台词原文完整，角色和画内/画外身份明确。
- [ ] 同一说话人跨 Shot 使用稳定 `(S1)`、`(S2)`，没有重新编号。
- [ ] 对白和歌词使用 `<d>[Language] ...</d>`；跨镜台词有 `<scenetrans>`；截断台词有 `<cutoff>`。
- [ ] 台词长度与 Shot 时长匹配；画外音说明对应画面人物嘴唇闭合。
- [ ] 字幕、Logo、标题、按钮和 UI 文案逐字写出，并标明位置、时间和可读性。
- [ ] `overall_soundscape` 只总结环境声、动作声和非语言人声，不重复对白或歌曲。
- [ ] `non_diegetic_music` 只描述角色听不到的背景音乐，写明乐器、速度、节奏和动态。
- [ ] 用户未要求音乐时没有主动添加 BGM；明确不要音乐时使用 `N/A`。
- [ ] 音频完整复用、片段复用、音色参考和节奏参考有明确边界。

### 官方输出协议

- [ ] 基础模式字段顺序为 `integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music`。
- [ ] Ref2VA 字段顺序为 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music`。
- [ ] 用户解释层和最终 prompt 层没有互相混淆。
- [ ] 最终 prompt 默认使用官方英文结构；对白、歌词、字幕、Logo 和 UI 文案保持原文。

### 限制与提醒

- [ ] 时长在 4–15 秒内；帧率、画幅和素材数量没有被写成未经验证的上传结果。
- [ ] 图片、视频、音频和混合文件没有超过已知 H3 上限；超限时给出筛选或分批方案。
- [ ] 提示词不超过 7000 字符；超长时只压缩重复修饰，保留核心事实和限制。
- [ ] 必要提醒只包含真实冲突、假设或限制。
- [ ] 没有静默丢弃用户素材、台词、文字或修改项。

### 风格路由

- [ ] 只有用户明确风格或任务意图时才启用风格路由。
- [ ] 已从官方八种风格中选择正确路由，或明确退回通用模式。
- [ ] 风格约束没有覆盖用户明确的模式、素材、主体、台词和禁止项。
- [ ] 风格配置只增加视觉、节奏、声音、文字和生产阶段约束。
- [ ] 风格不匹配时说明必要假设；新增风格遵循同一配置结构。

## 代表性验收场景

| 编号 | 场景 | 必须验证 |
|---|---|---|
| 1 | 无素材的 15 秒 16:9 电影感创意 | T2VA；完整画面、镜头、声音和禁止项 |
| 2 | 单人物图，用户明确“作为首帧” | I2VA；0.00 秒首帧；连续发展 |
| 3 | 两张图，明确首帧和尾帧 | FL2VA；连续补间；最后状态到位；不自动切镜 |
| 4 | 单图但只说“参考人物外观” | 普通参考图；不误判 I2VA |
| 5 | 单张尾帧图 | L2VA；前置状态推测；尾帧落在视频末端 |
| 6 | 人物图、场景图、产品图分别上传 | Ref2VA；Subject/Picture 标签稳定；角色不混淆 |
| 7 | 原视频中的猫替换为图片中的狗 | Video Editing；保持原镜头、动作和时序 |
| 8 | 从原视频结尾继续人物动作 | Video Continuation；不重复动作；保持空间和声音连续 |
| 9 | 原视频保留原音乐，另用音频参考音色说新台词 | Audio Reuse 与 Audio Reference 分开；台词、口型和 speaker ID 正确 |
| 10 | 两人对话跨镜并出现具体英文按钮 | Speaker ID、`<scenetrans>`、原文按钮和可读性 |
| 11 | 超过 12 个混合素材或提示词超过 7000 字符 | 不静默丢弃；给优先级/分批方案；压缩重复修饰 |
| 12 | 产品广告、MV、纸艺、3D、游戏开场、手绘实拍请求 | 正确命中八种风格；普通请求不误触发风格 |

## 错误处理

- 素材编号冲突：显示冲突、采用最明确的用户映射，不擅自重排。
- 素材用途不明：根据语义给最低风险假设；只有会改变模式时才提醒。
- 首尾帧与多镜头冲突：优先保留用户明确的模式要求，并提醒另一种模式的影响。
- 音乐与无音乐冲突：采用最新且更具体的指令。
- 文件数量或时长超限：列出超限项，给出保留高优先级素材或拆批方案。
- 提示词超长：删除重复形容词、同义句和不影响执行的装饰，不能删除台词、数字、时间线、素材绑定和禁止项。
- 风格不匹配：退回通用 H3 模式，并说明未启用风格路由的原因。
