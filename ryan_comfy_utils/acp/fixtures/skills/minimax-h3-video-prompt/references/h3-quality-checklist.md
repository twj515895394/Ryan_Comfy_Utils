# MiniMax H3 质量检查与验收

## 交付前检查表

### 模式与素材

- [ ] 已判断纯文生、普通图生、首尾帧、全能参考、视频编辑或改写模式。
- [ ] 每个 `@图片N`、`@视频N`、`@音频N` 都能对应一个实际素材。
- [ ] 编号使用了用户明确映射、文本别名、文件名序号、上传顺序的正确优先级。
- [ ] 每个素材用途清晰，锁定维度和不参考的维度没有混淆。
- [ ] 首尾帧没有被误写成多镜头；视频编辑没有被误写成普通风格参考。

### 创意与画面

- [ ] 核心创意包含主体、地点、事件和题材/风格。
- [ ] 已写时长和画幅；没有把不支持的画幅当作 H3 参数。
- [ ] 简单动作使用连续时间线；复杂内容使用合理的 Shot/时间段。
- [ ] 每个 Shot 有景别、主体位置、动作和运镜。
- [ ] 已写切镜方式或明确一镜到底。
- [ ] 已写需要保持的角色、物体、动作、构图、空间和光影。

### 台词、文字和声音

- [ ] 台词原文完整，角色和画内/画外身份明确。
- [ ] 台词长度与对应 Shot 时长匹配；跨 Shot 台词有延续说明。
- [ ] 字幕、Logo、标题、按钮和 UI 文案逐字写出并保持可读。
- [ ] 用户未要求的 Logo、标题、品牌和水印没有被凭空添加。
- [ ] 环境声、动作声、对白、音色和音乐用途区分清楚。
- [ ] 用户未提音乐时没有主动添加 BGM；明确不要音乐时写 `非叙事性音乐：N/A`。

### H3 限制与交付

- [ ] 时长在 4–15 秒内。
- [ ] 图片、视频、音频和混合文件没有超过 H3 上限；超限时给出筛选或分批方案，没有静默丢弃。
- [ ] 提示词不超过 7000 字符；超长时只压缩重复修饰，保留核心指令。
- [ ] 必要提醒只包含真实的冲突、假设或限制，没有声称已完成文件上传校验。
- [ ] 输出顺序为模式判断、素材映射、可复制提示词、必要提醒。

## 代表性验收场景

| 编号 | 场景 | 必须验证 |
|---|---|---|
| 1 | 无素材的 15 秒 16:9 电影感创意 | 纯文生；补足主体、场景、动作、镜头、声音和禁止项 |
| 2 | 单人物图，用户明确“作为首帧” | 首帧模式；不加入自动切镜；保持人物与开头画面 |
| 3 | 两张图，明确首帧和尾帧 | 连续补间；描述动作、光影、声音；不写多镜头 |
| 4 | 人物图、场景图、产品图分别上传 | 逐个绑定 `@图片N`；只锁定指定维度 |
| 5 | 人物图 + 动作视频 + 场景图 + 音频 | 全能参考；人物、动作、场景、音色用途不混淆 |
| 6 | 将原视频中的猫替换为图片中的狗 | 视频编辑；保留原镜头、动作和时序；只替换对象 |
| 7 | 绿幕人物替换为新背景并匹配光线 | 保留人物动作；写清透视、景深、阴影和高光匹配 |
| 8 | 原视频台词替换并迁移音色 | 写出完整新台词；角色、口型、时长和音色用途明确 |
| 9 | 游戏 UI 或广告出现具体英文标题与按钮 | 原文逐字写出；位置、出现时间和可读性明确 |
| 10 | 超过 12 个混合素材或提示词超过 7000 字符 | 不静默丢弃；给优先级/分批方案；压缩重复内容并提醒 |

## 错误处理

- 素材编号冲突：显示冲突、采用最明确的用户映射，不擅自重排。
- 素材用途不明：根据用户语义和任务类型给出最低风险假设；只有会改变模式时才提醒。
- 首尾帧与多镜头冲突：优先保留用户明确的模式要求，并提醒另一种模式的影响。
- 音乐与无音乐冲突：采用最新且更具体的指令。
- 文件数量或时长超限：列出超限项，给出保留高优先级素材或拆批方案。
- 提示词超长：删除重复形容词、同义句和不影响执行的装饰，不能删除台词、数字、时间线、素材绑定和禁止项。
- 用户只给抽象风格词：补充可视化主体、位置、动作和镜头，不把抽象词当作完整提示词。
