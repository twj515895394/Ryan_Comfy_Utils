# MiniMax H3 提示词规则

## 模型与输入限制

- 输出时长：4–15 秒。
- 输出帧率：24 FPS。
- 输出声音：结果带原生双声道声音。
- 文生视频和全能参考支持：21:9、16:9、4:3、1:1、3:4、9:16；首尾帧模式遵循输入图片原始比例。
- 首尾帧入口：图片 0–2 张，图片宽高 256–5760；无图片时为文生视频。
- 全能参考入口：图片最多 9 张；视频最多 3 段，单段 2–15 秒、总时长不超过 15 秒；音频最多 3 段，必须和图片或视频一起使用；混合输入总上限 12 个文件。
- 格式：图片支持 JPG、JPEG、PNG、WEBP、HEIC、HEIF；视频支持 H.264/AVC、H.265/HEVC；音频支持 WAV、MP3。
- 单文件大小：视频 50 MB、图片 30 MB、音频 15 MB；API 请求体 64 MB。
- 提示词上限：不超过 7000 字符。

限制是提示词编排时的提醒，不代表 Skill 已经验证用户文件实际满足限制。不要声称素材已通过上传校验。

## 模式判断

### T2VA：纯文字生成

无参考素材时使用。补充可见主体、空间关系、动作、镜头、声音和风格，构造完整视听时间线。

### I2VA：首帧向后发展

只有用户明确指定首帧时使用。首帧对齐 `0.00` 秒；先建立首帧中的主体、构图、服装、关键物体和空间锚点，再描述向后的连续动作。

### FL2VA：首尾帧连续补间

只有用户明确指定首帧和尾帧时使用。描述第一帧到最后一帧的动作、姿态、物体状态、构图和光线变化；默认单一连续镜头，不自动加入切镜。最后一帧必须落在视频末端。

### L2VA：向尾帧收敛

只有用户明确指定尾帧且没有首帧时使用。先推测与尾帧相容的前置状态，再让动作、镜头、空间和物体状态逐步收敛到最后有效时刻；不要把尾帧图片放到 Shot 1。

### 普通图片参考

图片用于人物、物体、场景、构图或风格参考，但没有关键帧身份时使用。单张图片不默认是首帧或尾帧。

### Ref2VA、视频编辑和续接

- 多图片、视频、音频共同参与生成时使用 Ref2VA，并为每个素材定义独立角色。
- 原视频被直接修改时使用视频编辑结构，保护未修改内容。
- 从原视频结尾继续时使用视频续接结构，保持最后有效状态，不重复已完成动作。
- 原声音完整或部分复制时标记音频复用；只借鉴音色、节奏或质感时标记音频参考。

## 官方字段与引用标签

基础模式按以下顺序输出：

```text
integrated_multimodal_description: ...
overall_soundscape: ...
non_diegetic_music: ...
```

Ref2VA 按以下顺序输出：

```text
subject_definitions: ...
summary: ...
retention_analysis: ...
detailed_description: ...
overall_soundscape: ...
non_diegetic_music: ...
```

用户层使用 `@图片N`、`@视频N`、`@音频N`；最终结构可映射为 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>`。标签一旦分配，跨所有字段保持含义和编号稳定。

视觉引用关系：`fully_preserved`、`partially_preserved`、`attribute_transfer`、`weak_reference`。音频关系：`fully_copy`、`partially_copy`、`reference`、`weak_reference`。

## 视频输入限制

限制是提示词编排提醒，不代表 Skill 已验证用户文件。不要声称完成上传或媒体校验。

## 素材角色词典

使用下列角色并写出锁定范围：

- 人物参考：脸、发型、体型、服装、身份和表演气质。
- 物体参考：产品形状、材质、颜色、标志性结构和比例。
- 场景参考：地点、空间结构、光线、色调、天气和氛围。
- 风格参考：影像质感、色彩、颗粒、动画媒介、剪辑包装和审美语言。
- 构图参考：主体位置、景别、视角、遮挡、画面比例和空间层次。
- 首帧/尾帧：视频开始或结束时必须保持的画面状态。
- 动作参考：动作轨迹、节奏、身体姿态和表演方式。
- 运镜参考：推拉摇移、跟拍、手持、镜头高度、转场和运动节奏。
- 故事版参考：按故事版分镜组织镜头，不把参考图中文字或 Logo 自动复制进成片。
- 音色参考：声音身份、音色、语气或演唱质感；台词仍需写出原文。
- 音频复用：复用全部声音或明确的某一时间段/轨道。
- 视频编辑：把视频作为被修改对象，而不是只作为风格参考。

同一素材可以多角色，但必须写成“锁定 A；仅参考 B；不要参考 C”。

## 参考与文字控制

- 有直接关联的元素持续使用相同 `@` 标签或官方引用标签，避免使用无法绑定的“参考图”。
- 具体标题、标语、按钮、字幕、Logo 文案逐字写出，使用英文双引号包裹，并说明出现时间、位置和可读性。
- 不要复制原参考图中未指定的品牌、Logo、标题或可识别文字。
- 少写抽象比喻，多写摄影机可以看到的主体、位置、动作、材质、光线和镜头变化。

## 镜头、时间与台词

- 第一镜使用 `[Shot 1]`，默认不添加切镜时间。
- 后续 Shot 使用严格递增的 `MM:SS.mmm` 切镜时间。
- 关键帧对齐时间使用两位小数，例如 `0.00`、`8.00`。
- 单一连续动作或一镜到底使用连续时间线，不堆叠 Shot 标签。
- 多事件、多场景或强节奏内容按 Shot 拆分。
- 每个 Shot 写景别、主体位置、动作、镜头运动、切换方式、台词和音效。
- 镜头运动在需要时同时表达类型、幅度和速度，例如 `pushes in with small amplitude at slow speed`。
- 说话人使用稳定 `(S1)`、`(S2)`；同一说话人跨 Shot 不重新编号，多人合说使用组合 ID。
- 对白和歌词原文写入 `<d>[Language] ...</d>`，不翻译、不概括。
- 一句台词跨镜时使用 `<scenetrans>` 并明确声音连续；视频结束截断时使用 `<cutoff>`。
- 画外音明确写出 `off-screen voiceover`，并说明对应画面人物嘴唇闭合。

## 镜头运动词典

- `Zoom In / Zoom Out`：变焦，摄影机机身保持不动。
- `Push In / Pull Out`：摄影机前进/后退。
- `Pan Left / Pan Right`：原地水平摇摄。
- `Truck Left / Truck Right`：摄影机水平平移。
- `Tilt Up / Tilt Down`：垂直摇摄。
- `Pedestal Up / Pedestal Down`：摄影机整体升降。
- `Arc Shot`：围绕主体弧线运动。
- `Tracking Shot`：跟随移动主体。
- `Static Shot`：摄影机与镜头保持静止。
- `POV`：主体视角。
- `Roll Clockwise / Roll Counterclockwise`：镜头滚转。
- `Shake Slightly / Shake Strongly`：轻微/明显抖动。

幅度可使用 `with small amplitude` 或 `with large amplitude`；速度可使用 `at slow speed` 或 `at fast speed`。

## 声音策略

- `integrated_multimodal_description` / `detailed_description`：对白、歌唱、现场广播、电视/手机音乐等画内声音。
- `overall_soundscape`：1–4 句全片环境声、动作声和非语言人声；不重复对白、歌词和画内音乐。
- `non_diegetic_music`：角色听不到的背景音乐，描述乐器、速度、节奏和动态；无音乐使用 `N/A`。
- 用户未提音乐时不主动添加 BGM；用户明确不要音乐时写 `non_diegetic_music: N/A`。
- 参考音频必须明确是完整复用、片段复用、音色参考、节奏参考还是弱参考，不能混写。

## 冲突与超限处理

- 编号冲突：采用用户明确映射，不静默重排。
- 用途冲突：拆成严格保持、仅参考、允许改变；无法判断时说明冲突。
- 音乐与无音乐冲突：以最新且更具体的指令为准。
- 首尾帧与多镜头冲突：默认连续补间；用户明确多镜头时改用 Ref2VA/多模态表达。
- 素材超限：不静默丢弃，给出优先级筛选或分批方案。
- 提示词超长：删除重复形容词和装饰句，但保留主体、动作、时间线、台词、文字、声音、素材绑定和禁止项。
