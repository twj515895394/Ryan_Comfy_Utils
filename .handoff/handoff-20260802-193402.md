# Handoff Document - ComfyUI Image & Video Generator Node Development

## Summary of Completed Work

We have successfully designed, developed, and verified two major custom ComfyUI nodes for image and video generation and editing. The entire test suite containing 102 tests is fully passing.

### 1. Description Completion
- Added `DESCRIPTION` class attributes to all 12 custom nodes in the repository, making them searchable with detailed inline documentation on the ComfyUI frontend.

### 2. Ryan Image Generator (`RyanImageGenerator`)
- Supported single image prompt txt2img, and up to 5 optional inputs for img2img / image editing.
- Implemented **Dual-routing API mechanism**:
  - **Gemini mode** (via `/chat/completions`): routes multimodal prompts and reference images, extracting base64 images from choice messages.
  - **Grok/GPT mode** (via `/images/generations`): routes standard parameters and base64 arrays in the custom `"images"` payload key.
- Verified on local proxy (`8317`): `grok-imagine-image`, `grok-imagine-image-quality`, and `gemini-3.1-flash-image` generated image tensors successfully.

### 3. Ryan Video Generator (`RyanVideoGenerator`)
- Integrated with frontend slot count updates (1..5 reference slots).
- Supported **Adaptive video modes**:
  - **Text-to-video**: no image input.
  - **Image-to-video (first frame)**: 1 image input. Passed to API payload as `"image": {"url": "data:image/..."}`.
  - **Reference-to-video**: >1 image input. Passed to API payload as `"reference_image_urls": [{"url": "data:image/..."}, ...]` to ensure consistency using prompt references like `@image1`.
- Built async task post, polling loop (checking `/v1/videos/{request_id}` status transitions: `pending` -> `done` / `failed`), and down-stream video downloading to the `output` directory.
- Decoded output video frames into PyTorch tensors using `load_video_frames` for direct ComfyUI node connections, returning both `IMAGE` frames and the local video file path `STRING`.

### 4. Dropdown Model Categorization
- Added `type: "chat"` and `type: "image"` attributes inside `llm_profiles.json`.
- Updated `config_loader.py` to filter profile listing. LLM Chat nodes only display chat/text models, while Image & Video Generator nodes display image/video models.
