Ryan Artifact Selector：让用户不用懂 UID

这是交互讨论稿，不是最终 ComfyUI 页面。三个方案都假设：上游 Agent 已经 Chat → Commit，并且 Queue 过一次；否则节点会明确告诉用户缺哪一步，而不是静默输出空白。

推荐：最少认知负担

A. 自动取上游最新产物

普通用户只需要选择“我要什么”。来源、ID、revision 全部由系统处理。

  • 默认：自动选择最新有效产物。
  • 可选：图像提示词 / 分镜提示词 / 视频提示词。
  • 没有产物时显示：“请先打开上游 Agent，完成 Commit，再 Queue”。

B. 简单模式 + 可选高级设置

默认仍然只看到语义选项；需要选具体镜头时，再展开“我要更精确地选择”。

  • 普通用户不接触 UID / output_id / kind。
  • 高级设置也只显示名称和标签。
  • 适合既要简单默认值、又要偶尔精确选镜头的用户。

C. 取消 Selector，Agent 直接输出

Workflow Agent 直接提供“图像提示词 / 分镜提示词 / 视频提示词”输出口；Selector 只留给少数需要跨 Agent 精确取值的场景。

✓ 连线即知道输出是什么
  • 最直观，适合固定流程。
  • 节点输出口会变多，画布更宽。
  • 跨多个上游来源时仍需要 Selector。
关键流转：连线只建立数据关系；Queue 才会执行上游节点；上游必须先 Chat → Commit 生成正式产物。当前空白的直接原因通常是“还没有可读取的结构化产物”，不是用户应该去填写 UID。
